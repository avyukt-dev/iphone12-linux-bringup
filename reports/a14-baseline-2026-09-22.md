# A14 / iPhone 12: reproducible source baseline

Date: 2026-09-22. Status: **SOURCE INVESTIGATION ONLY — NO A14 BOOT PATH VERIFIED**.

## Scope, device identity and evidence

- Target: iPhone 12, hardware model `iPhone13,2`, Apple BoardConfig `D53gAP`, SoC/platform `t8101` (Apple A14). Public firmware catalog: https://ipsw.me/iPhone13,2/info/ .
- **Physical-device observation supplied by the owner on 2026-09-22:** read-only `scripts/collect_device_facts.py` output reported `ProductType=iPhone13,2`, `HardwareModel=D53gAP`, `ProductVersion=27.0`, and `BuildVersion=24A437`; all four query statuses were `ok`. The first two script executions returned `device_query_failed` for all keys; the third completed successfully. The reason for the earlier failures is **unknown**, and no trust-dialog interaction was required during the successful query. The output is a report from the physical device through the previously trusted USB host; it is not an independently captured boot log.
- `D53gAP` is Apple's board configuration string, **not a verified Linux DTB filename suffix**. Do not assume that adding `t8101-d53g.dts` constitutes board support.

## Engineering decision

The source inventory and four-key device identity observation are complete. Next investigate a firmware-and-board-specific, reproducible authorized boot entry and device-safe diagnostic/recovery procedure; this remains blocked without evidence. Defer speculative A14 register writes, flash modifications, device-tree addresses copied from other SoCs, and kernel/bootloader hardware patches until G1 and verified hardware descriptions exist. Work on the kernel and bootloader remains on separate `research/iphone12-a14` branches.
