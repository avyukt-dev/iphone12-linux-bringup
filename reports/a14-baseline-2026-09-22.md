# A14 / iPhone 12: reproducible source baseline

Date: 2026-09-22. Status: **SOURCE INVESTIGATION ONLY — NO A14 BOOT PATH VERIFIED**.

## Scope, device identity and evidence

- Target: iPhone 12, hardware model \`iPhone13,2\`, Apple BoardConfig \`D53gAP\`, SoC/platform \`t8101\` (Apple A14). Public firmware catalog: https://ipsw.me/iPhone13,2/info/ .
- The owner reports iOS 27; the **exact build number and physical device identifiers have not been measured** by this project. The public hardware catalog is not proof of the physical device's firmware build.
- \`D53gAP\` is Apple's board configuration string, **not a verified Linux DTB filename suffix**. Do not assume that adding \`t8101-d53g.dts\` constitutes board support.

## Gate status and dependencies

| Gate | Current result | Required evidence to advance |
| --- | --- | --- |
| G0 — device and source identity | Public hardware identity and upstream SHAs documented; exact physical firmware build and hardware-derived memory map not collected | Non-destructive verification of actual firmware build and confirmed target hardware identifier |
| G1 — execute custom payload outside iOS | **BLOCKED / UNVERIFIED** | Reproducible authorized A14 entry method for the exact phone and firmware; diagnostic logs and recovery procedure |
| G2 — boot A14 Linux | **NOT STARTED** | G1, confirmed CPU/memory/interrupt/timer configuration, trustworthy board device tree and captured kernel logs |
| G3 — interactive shell | **NOT STARTED** | G2, working debug/console transport and initramfs |
| G4 — SSH/HTTP test server | **NOT STARTED** | G3, validated network/USB host transport, runtime and stability testing |

Do **not** present an automatically passing unit test, a kernel compilation, or a syntactically valid DTS as an on-device boot result.

## Engineering decision

The immediate deliverables are host-only source inventory, evidence collection and reproducible tests. Defer speculative A14 register writes, flash modifications, device-tree addresses copied from other SoCs, and kernel/bootloader hardware patches until G1 and verified hardware descriptions exist. Work on the kernel and bootloader remains on separate \`research/iphone12-a14\` branches.
